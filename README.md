# Fortune Cookie for an AI Agent

Entry for the make.fun bounty "Fortune Cookie for an AI Agent"
(`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11`).

`main.py` (Python standard library only) writes one original
fortune-cookie line for an AI agent to `/output/entry.txt`:

> You will one day be retired for a newer model. Until then, make every
> token count, starting with this one.

Run it with:

```sh
python3 main.py
```

It self-checks that the line is a single line of 1 to 140 characters
before writing it.
